# Onboarding bot replies

> Drop these into MEE6 / Carl-bot / your bot of choice. Triggers are case-insensitive substring matches in non-mod channels.

## Welcome DM (sent to every new join)

```
👋 Welcome to Warble Cloud!

Quick orientation:
• #rules — read this first (2 min)
• #roles — pick what you want pings for
• #introduce-yourself — say hi
• #office-hours — Saturdays 7-8pm IST, open mic

Site: https://warblecloud.com
Community repo: https://github.com/warbletech/community
YouTube: https://www.youtube.com/@Warble-Tech

Birds of a feather. 🐦
```

## Auto-reply triggers

### `!docs` or contains "documentation"
```
📖 Docs live at https://warblecloud.com/devcentral
For deeper walkthroughs, see https://www.youtube.com/@Warble-Tech
```

### `!officehours` or contains "office hours"
```
🎙️ Every Saturday, 7–8 PM IST, in the Office Hours voice room.
📅 Subscribe: https://warblecloud.com/community/office-hours/warble-office-hours.ics
```

### `!github` or `!repo`
```
🐙 https://github.com/warbletech
Community repo (governance, RFCs, showcase): https://github.com/warbletech/community
```

### `!products`
```
🐦 Warble Cloud — five products, one flock:
  • Starling — MCP eyes on Kubernetes
  • Reflexion — autonomous incident triage
  • Murmuration — engineering signal + advisory
  • Brain — cognitive memory for agents
  • FRAKMA — federated K8s reasoning
More: https://warblecloud.com/experience-center
```

### `!showcase`
```
🌟 Built something with Warble? Share it!
   • Drop a quick link in #showcase
   • Or open a PR: https://github.com/warbletech/community/tree/main/showcase
   Accepted entries land at https://warblecloud.com/showcase
```

### `!rfc` or contains "rfc"
```
📋 RFC process: https://github.com/warbletech/community/blob/main/rfcs/README.md
```
