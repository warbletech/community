# Showcase

Built something with Warble Cloud? Add yourself.

Accepted entries appear at [warblecloud.com/showcase](https://warblecloud.com/showcase).

## What we accept

- Customer stories — running Warble in production
- Talks / podcasts / blog posts that mention Warble or its products
- Open-source projects built on Warble (plugins, integrations, MCP tools)
- Workshops, tutorials, course modules
- Demos at meetups or conferences

We don't accept generic "thoughts on AI ops" — there must be a clear connection to Warble Cloud, Starling, Reflexion, Murmuration, Brain, or FRAKMA.

## How to submit

1. Copy [`TEMPLATE.md`](TEMPLATE.md) to `showcase/<slug>.md`
2. Fill in the frontmatter and body
3. Open a PR — title: `showcase: <your title>`
4. A maintainer reviews within 5 business days

## Frontmatter fields

| Field | Required | Notes |
|---|---|---|
| `title` | yes | The thing's name |
| `author` | yes | GitHub handle, optionally with display name |
| `org` | no | Company / org name |
| `kind` | yes | One of: `customer-story`, `talk`, `blog`, `podcast`, `open-source`, `workshop`, `demo` |
| `tags` | yes | Subset of: `starling`, `reflexion`, `murmuration`, `brain`, `frakma`, `finops`, `gcp`, `k8s`, `mlops` |
| `url` | yes | Where to read / watch / use it |
| `image` | no | 1200x630 hero image (PNG/JPG); store in `showcase/images/` |
| `published` | yes | YYYY-MM-DD |
